# 소상공인 법률·행정 사전점검 서비스 범위와 데이터 수급 정리

작성일: 2026-04-15

## 1. 검토 목적

이 문서는 소상공인 법률정보 도우미 POC가 법제처 `Lawbot` 같은 기존 대민 법령검색 서비스와 어떻게 구분되는지, 어떤 사용자를 대상으로 삼을지, 지식베이스 데이터를 어디서 수급할지, 서비스 제공 범위를 어디까지 제한할지를 정리한다.

서비스의 기본 방향은 법률 자문이 아니라 **소상공인 법률·행정 사전점검**이다.

```text
법령을 대신 검색해 주는 서비스가 아니라,
소상공인의 창업·운영 상황에서 놓치기 쉬운 법률·행정 확인사항,
준비자료, 상담기관을 공식자료 기반으로 정리해 주는 서비스
```

## 2. 법제처 Lawbot과의 차별화

법제처 Lawbot은 “일상적인 질문으로 우리나라의 법령정보를 찾아보는 AI 검색 서비스”로 운영된다. 공식 화면은 `AI 법령검색`, `AI법·제도`, `자주 찾는 질문`, 상세검색을 중심으로 구성되어 있고, 법령 조문·별표·서식·행정규칙·소관부처·시행일자 등 법령검색 체계가 핵심이다.

따라서 이 POC는 Lawbot과 같은 “전 국민 대상 법령검색”을 목표로 삼지 않는다.

| 구분 | 법제처 Lawbot | 소상공인 법률·행정 사전점검 서비스 |
|---|---|---|
| 주 목적 | 자연어 기반 법령정보 검색 | 소상공인 상황별 확인사항 정리 |
| 대상 | 전 국민 | 소상공인·예비창업자 |
| 입력 방식 | 일상 질문 또는 상세 법령검색 | 업종, 단계, 직원, 사업장, 판매방식, 문서 유무 등 상황 입력 |
| 결과 | 관련 법령·조문·제도 검색 결과 | 관련 분야, 체크리스트, 추가 질문, 준비자료, 상담기관 |
| 강점 | 공식 법령검색 | 복합 상황 분류와 실행 준비 |
| 경계 | 법령정보 검색 | 개별 사건 판단·문서 작성·전문자격 업무 제외 |

차별화 문장:

```text
Lawbot이 “법령을 찾는 검색 서비스”라면,
이 서비스는 “소상공인의 상황을 법률·행정 분야별로 분해해
무엇을 확인하고 어떤 자료를 준비해야 하는지 알려주는 사전점검 서비스”다.
```

## 3. 소상공인 상황의 명확한 구분 기준

### 3.1 법적 기준

공식 법령상 소상공인은 소기업 중 상시 근로자 수 기준을 충족하는 자로 본다. 생활법령정보 기준으로 광업·제조업·건설업·운수업은 상시 근로자 수 10명 미만, 그 외 업종은 5명 미만 기준이 적용된다. 매출액은 중소기업기본법상 소기업 규모 기준과 함께 보아야 한다.

이 서비스는 소상공인 여부를 법적으로 확정하지 않는다. 사용자가 스스로 입력한 업종·근로자 수·단계 정보를 기준으로 “소상공인 가능성이 높은 상황”을 사전점검 대상으로 삼는다.

### 3.2 서비스상 대상자 구분

서비스 대상은 다음 조건을 우선 적용한다.

| 구분 | 입력 기준 | 서비스 처리 |
|---|---|---|
| 예비창업자 | 아직 사업자등록 전, 임대차·인허가·채용 준비 중 | 창업 전 확인사항 중심 |
| 초기 소상공인 | 사업자등록 완료, 직원 0~4명 또는 제조·건설·운수 등 0~9명 | 운영 체크리스트 중심 |
| 소규모 제조업 | 제조 품목·공정·설비·화학물질·폐기물 가능성 있음 | 공장·입지, 환경, 산업안전, 제품인증 분기 |
| 음식점·카페 | 조리·판매·배달·위생교육·영업신고 관련 | 식품위생, 임대차, 노무, 소비자 분기 |
| 온라인판매 | 통신판매, 환불, 표시·광고, 배송 관련 | 전자상거래, 소비자, 표시광고 분기 |
| 분쟁·처분 상황 | 계약분쟁, 임금체불, 영업정지, 과태료, 내용증명 수령 | 상담 준비자료와 기관 연결 우선 |

### 3.3 필수 상황 필드

질문 하나만으로 판단하지 않고, 다음 항목을 구조화해 수집한다.

| 필드 | 예시 |
|---|---|
| 업종군 | 음식점·카페, 제조업, 도소매, 온라인판매, 서비스업 |
| 사업 단계 | 창업 전, 계약 전, 운영 중, 폐업 준비, 분쟁 발생, 처분서 수령 |
| 직원 수 | 0명, 1~4명, 5~9명, 10명 이상 |
| 사업장 | 자택, 상가 임차, 공장 임차, 공유주방, 온라인 전용 |
| 판매 방식 | 오프라인, 배달, 온라인, B2B 납품, 수출입 |
| 위험 요소 | 조리, 제조설비, 화학물질, 폐수, 분진, 소음, 위험물 |
| 문서 상태 | 계약서 초안, 고지서, 처분서, 문자·이메일, 없음 |
| 긴급성 | 마감기한 있음, 이미 분쟁 발생, 일반 준비 |

## 4. 데이터 수급 원칙

### 4.1 우선순위

지식베이스는 신뢰도 순서에 따라 적재한다.

| 순위 | 자료 유형 | 용도 |
|---:|---|---|
| 1 | 국가법령정보 법령·조문·시행령·시행규칙 | 공식 법령 근거 |
| 2 | 법제처 생활법령정보 | 쉬운 해설, 생활 주제별 정리 |
| 3 | 부처 공식 표준서식·가이드 | 계약서, 근로계약서, 영업신고, 점검표 |
| 4 | 부처 FAQ·상담사례·법령해석 | 자주 묻는 질문과 해석상 쟁점 |
| 5 | 공공기관 상담·지원 채널 | 연결 대상과 상담 준비자료 |
| 6 | 공공 통계·시장자료 | 임대료·상권 등 법률 외 판단의 한계 표시 |

비공식 블로그, 카페 글, 광고성 법률사무소 콘텐츠는 기본 지식베이스 원천으로 쓰지 않는다. 필요한 경우 “참고 후보”로만 기록하고, 공식 근거 확인 전에는 답변에 사용하지 않는다.

### 4.2 분야별 핵심 수급처

| 분야 | 주요 수급처 | 사용 목적 |
|---|---|---|
| 법령 원문 | 국가법령정보 공동활용 Open API | 법령·조문·시행일 기준 저장 |
| 생활법령 | 찾기쉬운 생활법령정보 | 주제별 쉬운 해설과 FAQ |
| 상가임대차 | 법무부 표준계약서, 묻고답하기 40선, 국가법령정보 | 계약·권리금·환산보증금·관리비 |
| 노무 | 고용노동부 1350, 표준근로계약서, 근로기준 FAQ | 근로계약, 최저임금, 휴게, 주휴, 5인 미만 적용 |
| 식품위생 | 식약처, 식품안전나라, 지자체 위생과 안내 | 영업신고, 위생교육, 시설기준, 자가점검 |
| 소비자·환불 | 공정거래위원회, 1372 소비자상담센터, 한국소비자원 | 청약철회, 환불, 피해구제 |
| 제조업 | 중기부 비즈니스지원단, 산업안전·환경·제품안전 관련 부처 자료 | 공장·입지, 안전, 환경, 인증, 납품계약 |
| 행정처분 | 행정절차법, 개별법 처분기준, 지자체 안내 | 처분서, 의견제출, 이의신청, 기한 관리 |
| 상담 연결 | 대한법률구조공단, 법률홈닥터, 중기부 비즈니스지원단 | 전문가 상담·구제절차 연결 |

### 4.3 SQLite 적재 단위

서비스 데이터는 “법령 하나”가 아니라 “상황에서 쓸 수 있는 지식 단위”로 저장한다.

```text
source_documents
- 공식자료명, 기관, URL, 발행일, 확인일, 라이선스·이용조건

knowledge_units
- 주제, 적용 조건, 설명, 체크리스트, 근거자료, 답변 가능 범위, 답변 금지 범위

scenario_rules
- 업종군, 단계, 위험요소, 문서상태, 직원 수에 따른 분야 라우팅 규칙

referral_channels
- 대한법률구조공단, 1350, 1372, 지자체 위생과, 비즈니스지원단 등 연결 정보
```

## 5. 서비스 제공 방식

### 5.1 기본 흐름

```text
1. 사용자가 업종·단계·질문 입력
2. 소상공인 가능 상황인지 1차 분류
3. 업종군과 위험요소에 따라 여러 분야 동시 라우팅
4. 분야별 공식자료 지식팩 검색
5. 답변 가능 범위와 금지 범위 확인
6. 체크리스트·추가 질문·준비자료·상담기관 출력
7. 개별 판단이 필요한 항목은 전문가 상담 권고
```

### 5.2 결과 화면 구성

```text
[관련 가능 분야]
상가임대차 / 노무 / 식품위생 / 소비자 / 행정처분 / 제조업 안전 등

[지금 확인할 사항]
공식자료 기반 체크리스트

[추가로 필요한 정보]
답변 정확도를 높이기 위해 필요한 질문

[준비할 자료]
계약서, 처분서, 문자, 영수증, 근로계약서, 사업자등록증 등

[공식자료 근거]
자료명, 기관, URL, 확인일

[상담 연결]
어느 기관이나 전문가에게 문의해야 하는지
```

### 5.3 답변 등급

| 등급 | 의미 | 예시 |
|---|---|---|
| A | 공식자료로 바로 안내 가능 | 근로계약서 필수 항목, 환산보증금 계산식 |
| B | 상황 정보가 있으면 체크리스트 가능 | 카페 창업 전 위생·임대차·노무 확인사항 |
| C | 추가 정보 없이는 답변 보류 | 제조업 환경 인허가, 공장 등록 필요성 |
| D | 전문가 상담 권고 | 계약서 유불리 판단, 해고 가능 여부, 소송 전망 |

## 6. 제공 범위와 제외 범위

### 6.1 제공 가능

- 관련 법률·행정 분야 분류
- 공식자료 기반 일반 설명
- 체크리스트
- 추가 질문
- 준비자료 안내
- 상담기관 안내
- 표준서식 또는 공식자료에 있는 예시의 요약
- 위험 신호 표시

### 6.2 제공 금지

- 개별 사건 법률 판단
- 계약서 최종 검토 의견
- 계약서·내용증명·소장·지급명령 신청서 작성 대행
- 소송 가능성 또는 승패 전망
- 해고·계약해지·고소·신고 등 권리행사 지시
- 세금 신고 대행 또는 세액 확정 판단
- 임대료·권리금·보증금 적정성 단정
- 인허가 가능 여부 확정

기본 고지 문구:

```text
이 서비스는 공식자료를 바탕으로 관련될 수 있는 법률·행정 정보를 정리하는 사전점검 도구입니다.
개별 사건에 대한 법률 자문, 계약서 검토 의견, 문서 작성 대행, 소송 가능성 판단은 제공하지 않습니다.
```

## 7. 우선 구현 시나리오

처음부터 모든 업종을 열지 않는다. 소상공인성이 뚜렷하고 공공자료 수급이 가능한 시나리오부터 확장한다.

1. 카페·음식점 창업 전 준비
   - 상가임대차, 식품위생, 노무, 소비자, 사업자등록
2. 상가 계약 전 점검
   - 표준계약서, 특약 검토 후보, 관리비, 권리금, 원상복구
3. 아르바이트 채용 전 점검
   - 근로계약서, 최저임금, 휴게, 주휴, 5인 미만 사업장 적용
4. 온라인 판매·환불 대응
   - 청약철회, 환불, 표시·광고, 소비자상담
5. 소규모 제조업 창업 전 준비
   - 공장·입지, 산업안전, 환경, 제품인증, 노무, 납품계약
6. 영업정지·과태료 처분서 수령
   - 처분 사유, 의견제출 기한, 증빙자료, 상담기관

## 8. 서비스 차별화 결론

이 POC는 법령검색을 대체하지 않는다. 법령 원문 확인은 Lawbot과 국가법령정보센터로 연결한다.

이 서비스의 핵심 가치는 다음 세 가지다.

1. 소상공인 상황을 업종·단계·위험요소로 구조화한다.
2. 하나의 질문을 여러 법률·행정 분야로 나눠 사전점검한다.
3. 답을 단정하지 않고 공식자료, 준비자료, 상담기관으로 연결한다.

따라서 서비스명은 다음과 같이 정리할 수 있다.

```text
소상공인 법률·행정 사전점검 도우미
```
