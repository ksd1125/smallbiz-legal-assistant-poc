# 출처와 보안 정책

## 공식 출처 우선순위

1. 국가법령정보 공동활용 Open API
2. 법제처 국가법령정보센터
3. 법원 또는 공식 판례 제공 경로
4. 정부 부처, 지자체, 공공기관 고시와 안내문

## MCP 사용 기준

`korean-law-mcp`와 `lexguard-mcp`는 공식 출처 그 자체가 아니라 국가법령정보 Open API를 호출하기 위한 MCP 계층이다. 따라서 답변 근거에는 MCP 이름보다 원천 데이터인 국가법령정보, 법령명, 조문, 판례/해석례 정보를 우선 표시한다.

## 답변 원칙

- 법령명, 조문, 판례, 해석례는 출처 후보와 함께 제시한다.
- 출처가 불명확하면 "확인이 필요합니다"라고 쓴다.
- 개별 사건 판단이나 소송 전략으로 보이는 표현은 피한다.

## 금지 입력

사용자에게 아래 정보를 입력하라고 요구하지 않는다.

- 주민등록번호
- 계좌번호
- 전화번호
- 고객명
- 계약서 원문 전체
- 기관 내부 URL
- 영업비밀
- 비공개 상담 기록

## 고지문

아래 내용은 법률정보 탐색을 돕기 위한 참고자료이며, 개별 사건에 대한 법률 자문은 아닙니다. 구체적 판단이나 대응은 변호사, 공공 법률상담, 담당 행정기관을 통해 확인하세요.
