이 목업은 설명용 정적 HTML입니다. API 키, 개인정보, 계약서 원문을 저장하지 않습니다.

소상공인 법률·행정 사전점검 도우미

법령검색이 아니라 소상공인 상황을 분야별로 나눠 확인사항과 준비자료를 정리합니다.

법률 자문, 계약서 최종 검토, 문서 작성 대행, 소송 가능성 판단은 제공하지 않습니다.

서비스 범위

이 화면은 소상공인·예비창업자의 창업과 운영 상황을 법률·행정 분야별로 나눠 사전점검하는 서비스 구상안입니다. 법령검색을 대신하기보다 공식자료 기반 확인사항, 준비자료, 상담기관을 정리합니다.

  • 대상: 카페, 음식점, 제조업, 온라인판매, 상가계약, 직원채용, 행정처분 상황
  • 방식: 질문을 업종, 단계, 직원 수, 사업장, 위험요소, 문서상태로 구조화
  • 결과: 관련 분야, 체크리스트, 추가 질문, 준비자료, 공식근거, 상담 연결

화면 구성

  1. Codex형 일반 질의: 사용자가 무엇이든 질문하면 소상공인 관점으로 관련 분야를 먼저 정리합니다.
  2. 업종·상황 심화 점검: 업종군과 위험요소를 입력해 다중 분야 라우터 결과를 보여줍니다.
  3. 내부 데이터 흐름: 데이터 수급, 파싱, SQLite 적재, 라우터, 에이전트 분배 구조를 설명합니다.

제공하는 것

  • 공식자료 기반 일반 설명과 체크리스트
  • 상가임대차, 노무, 식품위생, 소비자, 제조업, 행정처분 등 관련 분야 분류
  • 상담 전 준비할 계약서, 처분서, 영수증, 근로계약서, 사업자등록증 등 자료 목록
  • 대한법률구조공단, 고용노동부 1350, 1372, 지자체, 비즈니스지원단 같은 연결 후보

제공하지 않는 것

  • 개별 사건 법률 자문, 계약서 최종 검토, 문서 작성 대행
  • 소송 가능성, 해고 가능 여부, 계약 해지 여부 같은 판단
  • 세금 신고 대행, 임대료·권리금 적정성 단정, 인허가 가능 여부 확정
  • 공식근거가 부족한 항목은 답을 단정하지 않고 추가 질문이나 상담 연결로 넘김

데이터 수급 현실성

목업 단계에서도 “가능한 데이터”와 “검수 없이는 쓰기 어려운 데이터”를 구분합니다. 현재 POC는 SQLite seed 데이터로 흐름을 검증하고, 실서비스 후보는 공식 API와 승인된 공개문서만 단계적으로 넓힙니다.

구분 수급 후보 처리 방식 서비스 답변 범위
자동 수급 가능 국가법령정보 Open API, 일부 공공데이터 API, 지방행정 인허가 데이터, 식품안전나라 공개 API 정기 수집, 변경일 기준 업데이트, 조문·인허가 항목 정규화, 출처·시행일 저장. 지방행정 인허가 데이터는 기존 LOCALDATA 폐쇄 공지에 따라 공공데이터포털 전환 확인 후 연결 관련 법령 후보, 인허가 확인 경로, 공식자료 링크
반자동 수급·검수 법무부 표준계약서, 고용노동부 표준근로계약서, 부처 안내서·FAQ, 생활법령 해설 문서 등록, PDF/HWP 파싱, 저작권·이용조건 확인, 사람 검수 후 지식 단위 승인 계약 전 체크리스트, 특약 검토 포인트, 준비서류, 상담 전 질문
답변 제한 권리금·임대료 적정성, 개별 계약 조항의 유불리, 인허가 가능 여부, 소송·해고 판단 통계나 상담기관 연결은 가능하지만 정답처럼 생성하지 않도록 답변 차단 규칙 적용 자료 준비 안내, 전문가 상담 연결, 추가 확인 질문

데이터 처리와 최신 기술 반영

  1. 출처 등록: 기관명, URL, 이용조건, 갱신주기, 적용 지역, 시행일, 수집일을 먼저 기록합니다.
  2. 파싱·정규화: 조문, 서식, 안내문을 소상공인 질문에 맞는 지식 단위로 나누고 업종·단계·위험요소 태그를 붙입니다.
  3. 검색 색인: SQLite 관계형 저장소에 원천과 버전을 남기고, 실서비스에서는 키워드 검색과 벡터 검색을 결합한 하이브리드 검색을 사용합니다.
  4. 라우터: 질의 재작성과 메타데이터 필터로 업종, 지역, 문서 유형, 시행일에 맞는 자료만 검색합니다.
  5. 답변 생성: 출처 추적, 근거 링크, 답변 가능 범위, 답변 제한 사유를 함께 표시합니다.
  6. 운영 검증: 대표 질문 평가 세트, 검색 점수, 무응답 사유, 사람 검수 이력을 남겨 품질을 반복 점검합니다.

Screen 1

Codex형 일반 질의

첫 화면은 “무엇이든 물어보는” 채팅형 UI입니다. 사용자는 법령명이나 분야를 몰라도 질문을 입력하고, 서비스는 소상공인 관점으로 관련 분야와 추가 확인 질문을 정리합니다.

안내
소상공인 창업·운영 상황을 입력하면 관련 법률·행정 분야, 확인사항, 준비자료, 상담기관을 정리합니다.
카페를 열려고 하는데 상가 계약과 직원 채용, 영업신고를 같이 준비해야 합니다.
